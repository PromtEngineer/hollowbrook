- **forward pass** — running the model on an input to produce a prediction (Ch. 04)
- **loss function** — a function of prediction and truth that returns one number, zero when perfect and larger the worse the prediction (Ch. 04)
- **backward pass** — computing the gradient of the loss with respect to every parameter by walking the computation graph in reverse (Ch. 04)
- **optimizer** — the rule that turns gradients into parameter changes (SGD, momentum, Adam, AdamW, Muon) (Ch. 04)
- **training step** — one trip round forward → loss → backward → optimizer step (Ch. 04)
- **neuron** — a unit that computes an activation function of a weighted sum of its inputs plus a bias (Ch. 04)
- **weight** — a learned multiplier on an input to a neuron; the entries of a layer's matrix (Ch. 04)
- **bias** — a learned constant added to a neuron's weighted sum (Ch. 04)
- **activation function** — a fixed non-linear curve (tanh, relu, silu) applied to a neuron's sum so that stacked layers can represent bends (Ch. 04)
- **layer** — a set of neurons that read the same inputs; in matrix form, one matrix multiply plus an activation (Ch. 04)
- **multi-layer perceptron (MLP)** — a chain of layers, each feeding the next (Ch. 04)
- **mean squared error (MSE)** — the average squared difference between predictions and targets (Ch. 04)
- **cross-entropy** — the negative log-probability a model assigns to the correct answer; the loss used for next-token prediction (Ch. 04)
- **derivative** — the slope of a function at a point: how much the output changes per tiny change of the input (Ch. 04)
- **gradient** — the vector of derivatives of the loss with respect to every parameter; points uphill (Ch. 04)
- **gradient descent** — repeatedly stepping every parameter a small amount against its gradient (Ch. 04)
- **learning rate** — the multiplier on the gradient (or optimizer update) that sets the size of each step (Ch. 04)
- **backpropagation** — the algorithm that applies the chain rule over a computation graph to obtain every parameter's gradient in one backward walk (Ch. 04)
- **chain rule** — the derivative of a composition is the product of the derivatives along the path (Ch. 04)
- **SGD** — stochastic gradient descent: gradient descent where each gradient is estimated on a random minibatch (Ch. 04)
- **minibatch** — a small random sample of training examples used for one step (Ch. 04)
- **momentum** — an optimizer that steps along a running average (velocity) of past gradients (Ch. 04)
- **Adam** — an optimizer that normalises each parameter's step by a running estimate of its gradient's magnitude (Ch. 04)
- **AdamW** — Adam with decoupled weight decay; the default LLM optimizer since 2019 (Ch. 04)
- **weight decay** — shrinking every parameter slightly toward zero on each step to discourage large weights (Ch. 04)
- **Muon** — a 2024–2026 optimizer that orthogonalises the momentum-averaged gradient of each weight matrix before stepping (Ch. 04)
- **learning-rate schedule** — a rule for changing the learning rate over training, typically warmup then decay (Ch. 04)
- **overfitting** — training loss keeps improving while performance on unseen data gets worse (Ch. 04)
- **validation set** — held-out data never trained on, used to detect overfitting and choose models (Ch. 04)
