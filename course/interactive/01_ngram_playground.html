Read this as: with a vocabulary of V words, an n-gram model has Vn possible contexts to learn, but the text only shows it a few hundred of them. That is why counting stops working as n grows — and why we will replace the count table with a neural network.
Challenge. Find an n at which Generate produces a loop (the same phrase repeating) and explain why it happens. Then find the n at which it just replays the training text word for word.
Show answer

With n = 2, each word only knows the one word before it. Whenever the corpus has a cycle like the → kite → flew → over → the, the sampler can go round it for ever, and it will if the counts along the cycle dominate (try a few seeds; "the" is the most common hub). With n = 3 most two-word contexts occur exactly once in a short text, so every choice is forced and the model reproduces the training text verbatim: that is memorisation, the other face of sparsity. n = 1 ignores context entirely and produces word salad.
