Show answer
The verifier. In MiniHarness.run_session the agent's run ends when the model replies without a tool call — stop_reason = "done" — but that is only a claim. The harness then calls self.verify(), which runs run_tests itself, and appends Verification: PASS or FAIL with the test output to PROGRESS.md; loop() starts another session unless the tests pass. The permission gate and hooks limit what the agent may do; the verifier decides whether what it did worked. Tests are the ground truth; the model's summary is not.
