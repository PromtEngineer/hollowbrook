Challenge. Without looking at the detail panel, say which stages are shared by every model type, and which single stage is the first one where the model sees a reward rather than a target token. Then click around to check.
Show answer

Every model type — base, instruct, reasoning, agentic — goes through the first five stages (raw text → curation → tokenizer → pretraining → mid-training) plus evals. The reward model / DPO stage is the first where the training signal is a preference or score rather than a next token to imitate (SFT still imitates tokens). RLVR then uses a verifiable reward from a checker instead of a learned one.
