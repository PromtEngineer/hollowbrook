Challenge. Make a and b orthogonal (dot product 0) without making either of them the zero vector. Then find a second, different way to do it. What is the cosine similarity of orthogonal vectors, and why might an embedding model want two unrelated words to end up like this?

Show answer

Any pair at 90°, e.g. a = (3, 0) and b = (0, 2), or a = (2, 2) and b = (−2, 2): dot = 2·(−2) + 2·2 = 0. Cosine similarity is dot ÷ (|a|·|b|) = 0. Orthogonal means "share nothing": neither vector can be predicted from the other. In a high-dimensional embedding space there is room for a huge number of nearly-orthogonal directions, which is how a model keeps unrelated concepts apart while letting related ones (cat/kitten) point the same way.
