Challenge. Which stages train on data the current model generated itself (on-policy), and which on data written by someone else (off-policy)? Why does the order SFT → preference → RLVR → distillation put the off-policy stages first?
Show answerOff-policy: SFT (human/synthetic demonstrations), DPO on a static preference set, classic RM training. On-policy: RLVR/GRPO (the policy samples, a verifier scores), on-policy distillation (the student samples, the teacher scores every token), and RLHF with a live reward model. Off-policy stages come first because they are cheap and only need the model to imitate; they give it the chat format and a sensible starting policy. On-policy stages need a policy that already produces some correct or acceptable samples (GRPO learns nothing from a group where every reward is 0), so they come after. Distillation's placement varies: Thinking Machines (2025) use OPD after SFT as a cheap substitute for RL; 2026 papers (arXiv 2604.13016) report it works best when the student already shares the teacher's thinking patterns, which SFT on teacher outputs provides.
