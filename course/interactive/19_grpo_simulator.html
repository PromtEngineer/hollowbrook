Per token: Lt = −min(ρt·A, clip(ρt, 1−εlow, 1+εhigh)·A). The clipped branch wins — and the gradient is exactly zero — when A > 0 and ρ > 1+εhigh (already pushed up enough) or A < 0 and ρ < 1−εlow (already pushed down enough). Raising εhigh lets low-probability tokens of good answers keep growing: DAPO's clip-higher, the fix for entropy collapse. This mirrors ppo_clip_loss / masked_mean in llm/rl.py. The "Perturb ratios" button draws per-token log-ratio noise (σ = 0.15) on top of each rollout's base ratio; in a real run ratios differ from 1 only when the same samples are reused (ppo_epochs > 1) or the sampler is stale. Do not read much into the loss value: with all ratios at 1 it equals −Σi wiLiAi, which is exactly 0 under sequence-level averaging (advantages sum to zero) and merely reflects the length–advantage correlation under token-level averaging. Its gradient is the signal.

Training run — the policy is a single Bernoulli parameter p = σ(θ), updated by the clipped GRPO gradient of the sampled groups (see note)

What is simulated: each step samples a fresh group of G answers from the current p, scores them, computes advantages exactly as above, then for each ppo epoch forms ρi = πnew(yi)/πold(yi) (p/pold for a correct answer, (1−p)/(1−pold) for a wrong one) and takes a gradient-ascent step on the clipped objective with ∇θ log π(yi) = 1−p (correct) or −p (wrong), spread evenly over the answer's Li tokens so that the aggregation choice matters. With 1 epoch every ratio is 1 and the clip never fires (as in policy_update); with more epochs it does. Rewards are the only signal — no KL term, as in DAPO / Dr. GRPO.

Challenge. Produce a group that gives zero learning signal and explain why. Status: signal present
Show answer

Any group whose rewards are all equal — all correct (P(correct) high) or all wrong (P(correct) near 0, or a prompt beyond the model's reach) — has ri − mean(r) = 0 for every member, so every advantage is 0 and the loss has no gradient no matter what the ratios are. Nothing in the group beat its siblings, so "group-relative" has nothing to say. With the std normalisation this is also where GRPO is numerically fragile: one lone wrong answer among 15 right ones gets a huge |A| (tiny std), which Dr. GRPO avoids by dropping the division. DAPO's dynamic sampling keeps sampling until the batch contains groups with mixed rewards, so the gradient batch is never padded with zeros. In the training run you can watch this happen: as p → 1 more and more groups are skipped, the effective batch shrinks and learning stalls — at the same time H(p) → 0, the entropy-collapse signature. Keep the format bonus in mind: with it on, "all correct" groups can still differ by 0.1, which produces advantages of size ±1 after normalisation from a difference that has nothing to do with correctness.
