What each knob did

Challenge. Find three different single-knob settings under which the second-best token can never be sampled, no matter the seed. For each, say what happens to the third-best token. Then find a setting where temperature alone (any value > 0) cannot achieve this.
Show answer

(1) top-k = 1: only the argmax survives. (2) top-p ≤ p₁ where p₁ is the best token's probability: the code removes every token whose cumulative mass before it already reaches top-p, and for the second token that mass is exactly p₁. (3) min-p > p₂/p₁: the second token is below the min-p fraction of the maximum. (4) temperature = 0 is greedy. In all four cases the third-best token dies with the second. A temperature above 0 never removes a token — it only rescales the gap — so on the two-way tie preset, where p₁ = p₂, no temperature can separate them, and neither can min-p (their ratio is exactly 1). top-k = 1 and top-p ≤ p₁ do break the tie, but only by sort order: which of the two equal tokens survives is an accident of how the sort ordered them, not a preference of the model.
