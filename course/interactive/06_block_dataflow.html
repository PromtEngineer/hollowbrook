Challenge. Find a configuration in which the embedding matrix is more than 50% of all parameters. Then find the smallest change that brings it under 25%. Which of the two models would you expect to be better at the same total N, and why?
Show answer

Take the nano preset and set V = 4096 (the course's default tokenizer size): the embedding is 4096 × 96 = 393,216 parameters against 295,584 in the blocks, so ≈ 57% of N. Any small d with a large V does it. The quickest way down is to widen or deepen the model (the blocks grow with d² and L, the embedding only with d), or shrink the vocabulary. At equal N, parameters in the blocks are what compute with the input; an embedding row is only used by one token, so a model that spends most of N on the embedding table is a lookup table with a tiny brain. This is why scaling-law fits (Chapter 9) count non-embedding parameters.
