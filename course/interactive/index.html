Interactive explainers Course outline

Twenty-one browser playgrounds, one per chapter that has one, from n-grams to agent harnesses. Plain HTML — open any file directly, no server needed.
How to use these. Each page opens on something already interesting, has a What to try box with two or three experiments, and ends with a Challenge you can check against a hidden answer. Read the chapter first, then play for ten minutes; every number on the page is computed for real (the maths, the optimisers, the simulations), so if a result surprises you, it is worth understanding why. Everything runs offline in the page — nothing is sent anywhere.
