What is simulated here (read this once)
There is no trained model on this page. Each token gets a 16-dimensional embedding from a seeded hash of its spelling, plus a shared "meaning" vector for hand-picked groups of related words (cat/it/kitten, sat/lay, mat/rug, the/a, ...), so related words start out pointing the same way. The projection matrices W_q, W_k, W_v (16×8 per head) are fixed random matrices from a seeded generator; head 1 uses the same matrix for queries and keys so that q·k measures similarity, head 2 uses independent ones and gets its structure from RoPE. Everything downstream — the dot products, the ÷√8 scaling, the mask, the softmax, the weighted sum — is the real computation from llm/model.py::Attention, and RoPE uses the same half-split pairing as apply_rope.
Challenge. Toggle the causal mask off and on. Explain exactly what changed in row 1 (the first token) and why its weight became exactly 1.000 in one of the two settings. Then do the same for the last row.
Show answer

With the mask on, token 1 may only attend to keys at positions ≤ 1, i.e. only itself; every other score in its row is set to −∞ before the softmax, so its single surviving weight is exp(s)/exp(s) = 1.000 whatever the score. With the mask off, the same row spreads over all tokens according to their scores. The last row is unchanged by the mask: it may already see every key. That asymmetry is why a decoder-only LM can be trained on every position in parallel: each position only ever uses information from its past, so the prediction for position i is a legal "next token" prediction.
